# Basic examples: Kibana and Grafana report tutorials

Each example builds one complete job in Anaphora, from start to finish.

## Available examples

| Example                                                                 | Description                                          |
|-------------------------------------------------------------------------|------------------------------------------------------|
| [Kibana Dashboard Report](./basic-examples/kibana-dashboard-report)     | Schedule a daily PDF report of your Kibana dashboard |
| [Kibana Alert](./basic-examples/kibana-alert)                           | Send notifications when conditions are met           |
| [Kibana Conditional Report](./basic-examples/kibana-conditional-report) | Reports that only send when criteria match           |
| [Grafana Dashboard Report](./basic-examples/grafana-dashboard-report)   | Capture and deliver Grafana dashboards               |

## Prerequisites

Before you start, make sure you have:

- Anaphora installed and running
- Access to a Kibana or Grafana instance. The examples use the public demos at `demo.elastic.co` and `play.grafana.org`.
- At least one delivery interface set up (email, Slack, etc.)

## Next steps

Start with the [Kibana Dashboard Report](./basic-examples/kibana-dashboard-report) example. It shows every step of one job.
